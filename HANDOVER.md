# Handover: if you are taking over Paida Roots

Thank you. This record exists so our families are never forgotten, and now you are looking after it.

## What you need to know

- **Everything is plain text.** People and families are simple `.yaml` files in `data/`. You can edit them in any text editor, or directly on github.com using the ✏️ button.
- **The website rebuilds itself.** When a change reaches the `main` branch, GitHub checks the data and republishes the site within a few minutes.
- **If the check fails,** open the **Actions** tab on GitHub and click the red ❌ run. It tells you exactly which file is wrong and why.
- **How to add a person or family:** see "Add a person" in [README.md](README.md).

## Maintainer checklist (do once, then yearly)

- [ ] Turn on 2-factor authentication on the GitHub account.
- [ ] Protect the `main` branch: Settings → Branches → add a rule that blocks force pushes and deletion.
- [ ] Name a **GitHub account successor**, a trusted relative: Settings → Account → Successor settings.
- [ ] Set up the Codeberg mirror (Codeberg → New migration → GitHub → tick "This repository will be a mirror").
- [ ] Save the repo to Software Heritage (https://archive.softwareheritage.org/save/).
- [ ] Once a year: download the repo as a ZIP, copy it to USB drives, and give them to family members.
- [ ] Once a year: publish a new Zenodo version.
